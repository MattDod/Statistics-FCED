# Statistics-FCED

## Project basics (Fire ignitions and human influence)

### Proposed research question
How did human-caused fire ignitions change before vs. after 2017 across Portuguese regions, and how are those differences associated with human-influence proxies (population density and road access)?

### Scope
- Compare **pre-2017** and **post-2017** periods
- Compare results by **region**
- Use descriptive statistics and inference techniques at a course-project level (not overly complex)

### Variables to use
- **Qualitative (2–3)**
  - Region
  - Period (Before 2017 / After 2017)
  - Ignition type/class (if available in dataset)
- **Quantitative (at least 3)**
  - Number of ignitions
  - Population density
  - Road-access proxy (e.g., road density or distance to roads)
  - Burned area (optional extra, if available)

### Minimal analysis plan
1. Clean and filter data for selected regions and years
2. Build period indicator (before/after 2017)
3. Produce descriptive graphics/tables by region and period
4. Perform inference tests for selected comparisons
5. Interpret practical implications and limitations
